# TypeOverride Asset Package

Working product name: TypeOverride

## Core identity
TypeOverride is a typography-first WordPress plugin identity. The uppercase A establishes the typography cue; the orange lowercase a represents the explicit local override. Baseline/cap-height guides reinforce typography without using Elementor branding.

## Recommended usage
- wp-admin sidebar: typeoverride-admin-menu.svg
- plugin page/header inside wp-admin: typeoverride-lockup-horizontal.svg or master mark + text
- WordPress.org plugin icon: icon.svg, with PNG fallbacks
- WordPress.org banners: banner-772x250.png and banner-1544x500.png
- documentation/readme graphics: horizontal or tagline lockup

## Visual rules
- Keep the A dark navy on light backgrounds.
- Keep the local-override a orange in full-color uses.
- Use monochrome only where the WordPress admin UI requires it.
- Do not use Elementor's logo or styling in the TypeOverride identity.
- Do not stretch, skew, rotate, or add additional effects to the mark.
- Preserve generous clear space around the Aa mark.
